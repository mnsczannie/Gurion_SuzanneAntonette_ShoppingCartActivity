# Shopping Cart System in C#
> Suzanne Antonette F. Gurion | BSIT 1-1

###Project Description


erm mamaya

This project is a console-based Shopping Cart System developed in C#.
It **allows** users to select products, enter quantities, validate inputs, and manage a shopping cart while tracking remaining stock.
The system **prevents** invalid inputs, duplicate cart entries, and over-purchasing beyond available stock. 
It also **computes** the total cost of the cart, applies discounts, and provides a summary of the purchase.
